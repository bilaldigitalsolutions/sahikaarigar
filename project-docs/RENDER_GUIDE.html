Deploy ke baad — sirf 2 minute wait
  1. Render khud npm install chalayega. 1–3 minute lagega.
  2. Upar Logs tab kholo. Aisi line dikhni chahiye:
    ✓ SahiKaarigar auth-server on https://sahikaarigar-auth.onrender.com
  3. Naye browser tab me kholo:
    https://sahikaarigar-auth.onrender.com/health
    Aisa dikhna chahiye → {"ok":true,"smsProvider":"console",...}
  4. Woh URL mujhe bhej do. Baaki sab (Firebase par live karna + test) main kar dunga.
!
Kuch galat ho gaya? (screen band / Cancel dab gaya)

Koi baat nahi, wapas aise pahuncho:

  1. dashboard.render.com kholo
  2. Upar right me New + dabao
  3. Blueprint choose karo
  4. Repo bilaldigitalsolutions/sahikaarigar select karo → Connect
  5. Phir wahi 4 box aayenge → upar wale step 1–5 dohra do
